| a | **Verb government: direct vs indirect object per verb** (which verb takes bare object vs *a*) | Self-reported hardest area — clitic *mechanics* are solid, the leak is purely *lexical*: knowing a given verb's category. Trap verbs: *telefonare/rispondere/chiedere* → indirect (Sp *llamar/preguntar* mislead); *ringraziare/pagare/aspettare/ascoltare/cercare/guardare* → direct (no *a*); *pensare a/tenere a/contare su* → neither clitic, needs the right preposition; *dimenticare(si)* → direct without *si* (*ho dimenticato le chiavi*) or *di* + object with *si* (*mi sono dimenticato delle chiavi*, mirrors Sp *olvidarse de*) — never *si* + bare direct object. Free-translation prompts keep getting dodged toward this; needs an explicit prompt (e.g. "using *si*...") instead. |
| d | Word stress (*accento tonico*) — unmarked in writing except on the final syllable — see `LEARNING_ROADMAP.md` → Foundations | Flagged proactively 2026-07-26, not yet tested — Spanish marks any exception to default stress with a written accent; Italian doesn't for non-final syllables, so there's no visual cue to lean on. Since stress isn't visible in written translation quizzes, needs a different drill format (explicit "where does the stress fall" prompts, or reading aloud). |

Watch for recurrence on other irregular stems. |

## Standing interference watchlist

Patterns to flag in any Italian Daniel writes.

**Syntax**
- *a* before direct-object people (a-personal carryover).

**Vocab slips**
- *bono* → *buono*
- *agora mismo* → *adesso* / *ora*
- *cada vez* → *ogni volta*
- *otra vez* → *di nuovo* / *un'altra volta*
- *temprano* → *presto* (twice in one quiz, 2026-07-23)
- *pero* → *ma* — slipped once 2026-07-25, corrected clean on immediate retest same day.
- *tranquilo* → *tranquillo* — slipped once 2026-07-25, corrected clean on immediate retest same day.
- *nerviosissimo* → *nervosissimo* — slipped once 2026-07-25, corrected clean on immediate retest same day.
- *dubbo/dubo* → *dubito* (*dubitare*, io form) — two different wrong shapes, both 2026-07-26, then correct on immediate retest same day — watch one more instance before dropping.
- *gridare* → *piangere* ("to cry") — *gridare* actually means "to shout/yell"; likely pulled in by Spanish *gritar* sounding similar. Slipped once 2026-07-27, retest pending.

**Morphology**
- Plural family members need the article: *i miei fratelli*, not *mio fratelli*.

## How to maintain this file

- Add a row once an error type **recurs** (2+ instances) in quiz or free writing, or Daniel flags it as a real struggle. A single isolated slip — even on brand-new material — is normal noise, not a pattern, and does **not** get a row.
- **Overwrite, don't append.** When a row's state changes, replace its note with the current picture — never stack a new dated paragraph next to the old one. Each row is a snapshot of where things stand *now*, not a log of every re-drill.
- Remove a row entirely once a clean drill confirms internalization — don't leave a "resolved" note behind.
- **Keep the `#` letters sequential (no gaps).** When a row is removed, re-letter every row after it so the column still reads a, b, c, … with no skip.
- **Every row's note carries a "last quizzed" date.** After quizzing a row and it's still weak, overwrite the note with today's date plus a brief bit of nuance on how the error is progressing (narrowing, same shape, new sub-case, etc.) — not just "still weak." If a row already carries today's date, it's done for the day: don't poke for it or re-quiz it again until a later day (see `RULES_LEARNING.md` → multiple-of-3 poke rule).
- Keep it short and clinical. Drill ideas, sequencing, and planned additions belong in `LEARNING_ROADMAP.md`.
